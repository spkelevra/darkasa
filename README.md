# darkasa

darkasa is a simple, opinionated image viewer/editor.
-  The idea behind the app was to emulate the feel of a specific older image viewer and cut some bloat out. Editing and Copying should be fast.

## Installation

Android: Download and install the APK > Enable storage permissions on first start
- edited photots will be stored in /pictures/darkasa

## Usage

Main Menu:
- Shows a focused image and a bottom bar for scrolling. The bottom bar is not cached, to cut back on storage use.
- Tap the focused image to fullscreen. Tap again to go back.
- Edit button redirects to an edit menu. Features include Paint (with Arrow, Rectangle, Blur for us KB writers) along with Text, Crop/rotate, Tune, Filter, Standard Blur, and Emojis.
- Double-Tapping any image in the UI, focused or bottom bar, will result in copying to clipboard immediately. All saved edits are copied to clipboard after accepting changes (checkmark icon)
